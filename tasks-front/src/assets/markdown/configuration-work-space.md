# Configuration de Gestion des Tâches

## 1. Configuration des Types de Tâches

### **1.1. Types de Tâches**
- **Tâche Maitre** : Représente un projet ou une activité principale.
  - **Exemple** :
    - **Nom** : Projet
    - **Préfixe** : `PROJECT`
- **Sous-Tâche** : Doit être liée à une Tâche Maitre et suit un flux de travail spécifique.

### **1.2. Flux de Travail**
- Décrit les différents états possibles des tâches.
- Chaque type de tâche doit être lié à un flux de travail.
- Les flux de travail peuvent être créés ou modifiés dans le menu **Flux de Travail**.

### **1.3. Champs Personnalisés**
Chaque type de tâche peut inclure des champs personnalisés pour stocker des informations spécifiques.

#### **Types de Champs Personnalisés**
1. **Utilisateur** : Sélection d'une personne.
2. **Texte** : Champ texte libre.
3. **Nombre** : Valeur numérique.
4. **Date** : Sélection d'une date.
