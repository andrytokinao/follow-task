DT-009

Case « M'assigner » à la création d'une tâche

La question « Voulez-vous vous assigner cette tâche ? », posée après chaque création, est remplacée par une case cochée par défaut dans le formulaire.

1. Besoin

Après chaque création de tâche, le panneau restait ouvert sur une question d'assignation : une étape de plus pour une réponse presque toujours « oui ».

2. Comportement

  • Case « M'assigner cette tâche », cochée par défaut, dans le formulaire de création — pour une tâche comme pour une demande.
  • Cochée : la tâche est créée puis assignée au créateur, avant que l'hôte recharge sa liste.
  • Plus de question après la création : le formulaire se referme aussitôt.
  • Un échec de l'assignation ne défait pas la création : avertissement « … créée, mais l'assignation a échoué ».
  • S'assigner ne demande aucun droit (IssueAccessService.checkCanAssignSelf).
