DT-019

Menu Outils : logiciels, modèles, tutoriels et liens en dossiers

Chaque espace de travail a un menu Outils (/working/:prefixe/outils) où les membres rangent des logiciels, des modèles de document, des tutoriels vidéo et des liens. Les types sont les dossiers racines ; sous un type, chacun crée ses dossiers. Un élément reste dans l'espace où il est créé, ou est partagé avec tous les espaces.

1. Écran

  • Dossiers racines fixes : un par type (TypeOutil). Ni renommés, ni supprimés.
  • Dossiers des membres sous un type, deux niveaux au plus. Tuile ou ligne ; menu ⋮ (Renommer, Supprimer) pour qui en a le droit.
  • Outils après les dossiers : icône (celle du fichier s'il n'y en a qu'un), titre, version, pastille 🌐 (tous les espaces) ou 💼 (cet espace). Clic : la fiche. Action directe : ouvrir le lien, ou télécharger le fichier unique.
  • Vue dossiers ou liste, retenue par navigateur (localStorage « outils-vue »).
  • Recherche (2 caractères au moins) : tous types et dossiers confondus, à plat, avec le chemin (« Logiciels › Sécurité »).
  • L'état est dans l'URL : outils/logiciel/12?q=vpn. Précédent, suivant et lien partagé rouvrent le même dossier.
  • Fiche : description (texte brut), lien, fichiers ; vidéo et son lus sur place, PDF et images dans un onglet, le reste téléchargé. Ajout de fichiers par le trombone ou en les glissant sur la fiche.

2. Création : rester dans l'espace ou partager avec tous

Créer un dossier ou un outil propose deux choix :

  • Rester dans nom de l'espace ouvert (par défaut) — visible seulement depuis cet espace ;
  • Partager avec tous les espaces — visible depuis tous les espaces de travail.

Sous un dossier réservé à un espace, seul le premier choix est possible : un élément partagé y serait invisible des autres espaces. Le formulaire suit le type : version (logiciel, modèle), lien obligatoire (lien) ou facultatif (logiciel, tutoriel), fichiers joints, envoyés juste après l'enregistrement.

Le partage est une colonne explicite (portee) et non « pas d'espace = partagé » : un élément ne devient jamais visible de tous par accident.

Règles de rangement (RangementOutil)

  • Un dossier ou un outil ne va que sous un dossier de son type.
  • Deux niveaux de dossiers au plus.
  • Un dossier partagé reçoit tout ; un dossier d'espace ne reçoit que des éléments de ce même espace.
  • Pas deux dossiers de même nom côte à côte (sans tenir compte de la casse).
  • Un dossier ne se supprime que vide.
  • Un outil dont le dossier n'est pas visible depuis l'espace s'affiche à la racine de son type : jamais perdu.

5. Fichiers

  • REST : POST /api/outils/{outilId}/fichiers (multipart, champ file), GET /api/outils/fichiers/{id}[?apercu=true]. Suppression : mutation supprimerFichierOutil.
  • Disque : <app.storage.base-path>/outils/<id outil>/<uuid>.<extension>. Le nom envoyé par le navigateur n'entre jamais dans un chemin (pas de ../) ; le chemin est vérifié sous le dossier des outils.
  • Fichier écrit puis enregistré : si la base refuse, le fichier est effacé.
  • Type MIME déduit du nom, pas de l'en-tête du navigateur. Seuls vidéo, son, PNG, JPEG et PDF s'affichent dans le navigateur ; tout le reste (HTML, SVG…) est téléchargé, avec X-Content-Type-Options: nosniff.

8. Complément : icône d'un outil (2.0.41)

  • Chaque outil, un logiciel surtout, peut avoir son icône : champ « Icône » du dialogue d'ajout et de modification, qui ouvre le sélecteur d'icônes de l'application (DT-010, toutes les icônes Font Awesome). « Icône du type » revient à celle de son type.
  • Colonne outil.icone (VARCHAR 100, nullable), ajoutée par Hibernate au démarrage ; elle figure dans le seul script du menu, db/manual/2026-10-21-outils.sql. Champ icone de Outil et de OutilSaisie (GraphQL).
  • Le serveur n'accepte que des classes Font Awesome (ValidationOutil.icone, IconeOutilTest) : la valeur finit dans un attribut class.
  • Affichage : l'icône choisie d'abord (tuile, liste, fiche) ; sinon, un outil d'un seul fichier montre l'icône de ce fichier ; sinon, celle du type.
  • Correctif : la photo de l'auteur, dans la fiche, était un rond de 36 px dans une boîte de 22 et paraissait coupée ; sa taille passe par --avatar-size.
