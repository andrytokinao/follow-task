follow-task — conception et réalisation, un document par évolution.

Convention

  • Chaque document porte un numéro DT-xxx, repris dans son nom de fichier (DT-001-phases-projet.html) et dans le titre de chaque commit qui le réalise (« Phases 1/5 (DT-001) : … »).
  • git log --grep "DT-001" retrouve tous les commits d'un document.
  • Un document s'ouvre hors ligne : HTML, feuille assets/doc.css, diagrammes SVG intégrés.
  • Un script de migration manuelle, s'il y en a un, est cité dans le document (db/manual/).
