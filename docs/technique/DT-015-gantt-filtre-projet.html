DT-015

Gantt : filtre de chaque projet

Chaque projet du Gantt a son filtre : un mat-menu liste les types de tâche du projet, cochables ; décocher un type replie ses tâches. Le même menu range les tâches dans l'ordre d'exécution ou par type.

2. Règles

  • Le menu propose les types des tâches du projet, par nom, avec leur nombre (typesDuProjet).
  • Une ligne est masquée si toutes ses tâches sont d'un type décoché (masqueeParType) : en regroupement, un groupe mixte reste tant qu'un de ses types est coché.
  • Décocher tous les types laisse l'en-tête du projet, et son filtre : seul le choix de personnes (DT-014) masque un projet.
  • Par type : les types par nom, et dans un type l'ordre d'exécution (parDebut). Retour à l'ordre d'exécution sans reconstruire le diagramme.
  • Le bouton est teinté quand le projet a un filtre (type décoché ou ordre par type). Le filtre vit le temps de la page.
