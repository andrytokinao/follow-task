1. Besoin

Le sélecteur (app-choose-dialog) proposait 63 icônes écrites à la main, sans classement. Il fallait toutes les icônes possibles, groupées par catégorie, sans changer de version de Font Awesome si possible.

2. Comportement

  • Catégories à gauche (libellés traduits, nombre d'icônes) ; « Courantes » en tête reprend l'ancienne liste ; « Marques » en fin.
  • Recherche sur toutes les catégories, par nom et mots-clés Font Awesome (en anglais).
  • Ouvert en modale (app-icone-field, taille lg) ou dans un mat-menu (issutype-form2, [enMenu]="true" : sans en-tête, menu élargi).

4. Règles

  • Une icône par code Unicode : Icone.id (le caractère) est la clé primaire côté serveur. Les variantes regular partagent le code de la solid et l'écraseraient : seules solid et brands sont retenues.
  • Valeur enregistrée : fa-solid fa-… ou fa-brands fa-…. Les icônes déjà enregistrées (fa fa-…) gardent le même glyphe.
  • Font Awesome 7 non installé : version majeure, risque pour les icônes existantes ; la 6.7.2 suffit.
